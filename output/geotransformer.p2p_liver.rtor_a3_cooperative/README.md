# RTOR-A3 Cooperative final model

This directory contains the final published checkpoint for the
`geotransformer.p2p_liver.rtor_a3_cooperative` experiment.

## Published files

- `snapshots/best.pth.tar`: final inference checkpoint (stored with Git LFS)
- `run_manifest.json`: training command and resolved experiment configuration
- `group_split.json`: deformation-group split used by the run

The per-epoch checkpoints, resumable training snapshot, TensorBoard events,
logs, and generated registration results are intentionally excluded because
they are intermediate or derived artifacts.
